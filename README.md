# Firmware Monitor

Исходный код приложения находится в каталоге [`remote`](remote/README.md).

Быстрый запуск:

```bash
git clone https://github.com/Dron208104/firmware-monitor.git
cd firmware-monitor
git checkout v1.1.0
cd remote
chmod +x scripts/*.sh
./scripts/install.sh
```

Документация по установке, обновлению, резервному копированию и эксплуатации находится в [`remote/docs`](remote/docs/INSTALLATION.md).
