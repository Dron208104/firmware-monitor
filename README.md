# Firmware Monitor

Внутренний сервис контроля версий прошивок QTECH QSW-4610-28T-AC, Eltex MES2428P и D-Link DGS-1100-08V2 (с аппаратной ревизией). Сервис не устанавливает прошивки.

## Запуск на ALT Linux 11

Требуются Docker и Docker Compose. Создайте конфигурацию и обязательно замените секрет:

```bash
cp .env.example .env
sed -i "s/replace-with-long-random-value/$(openssl rand -hex 32)/" .env
docker compose up -d --build
curl http://127.0.0.1:8080/health
```

Интерфейс: `http://<адрес-сервера>:8080/`. SQLite хранится во внутреннем named volume и не публикуется наружу.

## Демонстрационные данные

Они никогда не создаются автоматически:

```bash
docker compose exec app python -m app.seed
```

В демоданных нет вымышленных версий и реальных адресов устройств; используются документальные адреса TEST-NET.

## Тесты

```bash
python3.13 -m venv .venv
. .venv/bin/activate
pip install -r requirements-dev.txt
pytest -q
```

## Резервное копирование

Остановите запись на время консистентной копии:

```bash
docker compose stop app
docker run --rm -v firmware-monitor_firmware_data:/data -v "$PWD/backups:/backup" alpine cp /data/firmware-monitor.db /backup/firmware-monitor-$(date +%F-%H%M%S).db
docker compose start app
```

Восстановление выполняйте только при остановленном приложении, предварительно сохранив текущую БД.

## Ограничения первой версии

- SNMP-интерфейс и профили подготовлены, но vendor-specific OID для версии требует подтверждённой документации конкретной модели.
- HTML официальных сайтов меняется. Если версия не распознана, сервис показывает «Не удалось проверить источник» и журналирует техническую причину; никаких демонстрационных версий не подставляется.
- Почтовая страница является безопасной заготовкой; SMTP-отправка не активирована.
- Проверка подключения инициируется пользователем. Планировщик проверяет только официальные страницы, но не сканирует локальную сеть.

## Безопасность

URL источника допускает только HTTP/HTTPS и после DNS-разрешения блокирует приватные, loopback, link-local и multicast адреса. Ответы ограничены по размеру и времени. Секреты профилей шифруются и не отображаются. `.env` исключён из Git. Контейнер работает непривилегированным пользователем с удалёнными Linux capabilities.
