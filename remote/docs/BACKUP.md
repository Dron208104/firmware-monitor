# Резервное копирование и восстановление

Сохраняйте SQLite-базу, `.env` с `ENCRYPTION_KEY` и номер установленного релиза.

```bash
./scripts/backup.sh
```

Копия появится в `backups/`. Перенесите её и зашифрованную копию `.env` во внешнее хранилище с ограниченным доступом.

Восстановление:

```bash
./scripts/restore.sh backups/firmware-monitor-20260925T120000Z.db
./scripts/verify.sh
```

Рекомендуется ежедневная копия, хранение не менее 14 дней, отдельная копия перед обновлением и ежеквартальная проверка восстановления.
