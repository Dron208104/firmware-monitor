# Безопасная эксплуатация

- Размещайте сервис в административной VLAN или за VPN.
- Используйте HTTPS и `SESSION_COOKIE_SECURE=true`.
- Не публикуйте порт 8080 в Интернет напрямую.
- Используйте SNMPv3 `authPriv`, если оборудование его поддерживает.
- Создайте отдельную SMTP-учётную запись с минимальными правами.
- Храните `.env` и резервные копии в защищённом хранилище.
- Ограничьте доступ к Docker daemon: он эквивалентен root-доступу.
- Регулярно обновляйте базовый образ и зависимости после тестирования.
- Назначайте наблюдателям только необходимые каталоги.

Технический аудит находится в `SECURITY_AUDIT.md`. Не добавляйте туда реальные адреса, пароли, community string или внутреннюю топологию.
