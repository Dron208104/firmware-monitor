# История изменений

Все заметные изменения Firmware Monitor фиксируются в этом файле. Формат версий: `MAJOR.MINOR.PATCH`.

## 1.1.0 — 2026-09-29

Стабильный релиз для пилотной эксплуатации в корпоративной сети.

### Добавлено

- светлая и тёмная темы с сохранением выбора пользователя;
- доступ наблюдателей только к назначенным каталогам оборудования;
- настройка получателей, типов событий и количества почтовых напоминаний;
- единые прикладные диалоги подтверждения и удаления;
- улучшенное отображение оборудования, действий и пустых состояний.

### Изменено

- MikroTik проверяется только по каналу RouterOS long-term;
- доработано получение и нормализация установленных версий через SNMP;
- выровнены действия «Скачать», «Изменения» и меню во всех состояниях;
- обновлены инструкции установки, эксплуатации и обновления.

### Безопасность

- устранена временная разница проверки существующего и неизвестного логина;
- ограничена память process-local лимитера попыток входа;
- SQL миграции переведены на параметризованные списки;
- усилены HTTP security headers и добавлен условный HSTS;
- удалены неиспользуемые frontend-файлы и генератор демонстрационных данных;
- повторный аудит: 0 High и 0 Medium по Bandit, известных CVE по pip-audit не найдено.

## 1.0.0 — 2026-09-25

Первый организационный релиз.

### Добавлено

- каталог оборудования, поиск, фильтрация и сортировка;
- проверка официальных источников QTECH, MikroTik, Eltex, D-Link и Zyxel;
- получение установленной версии по SNMPv1/v2c/v3;
- каталоги и разграничение доступа наблюдателей;
- администрирование пользователей и обязательная смена пароля;
- SMTP-уведомления и ограниченные повторные напоминания;
- автоматическая проверка по расписанию;
- Docker Compose, healthcheck, резервное копирование и восстановление;
- инструкции установки, обновления и эксплуатации.

### Безопасность

- Argon2 для паролей и Fernet для прикладных секретов;
- CSRF-защита, ограничение частоты входа и завершение неактивных сессий;
- проверка URL источников и SMTP-адресов;
- контейнер без root, Linux capabilities и повышения привилегий;
- безопасные HTTP-заголовки и ограничение размера запросов.
