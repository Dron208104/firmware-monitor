# История изменений

Все заметные изменения Firmware Monitor фиксируются в этом файле. Формат версий: `MAJOR.MINOR.PATCH`.

## 1.0.0 — 2026-09-25

Первый организационный релиз.

### Добавлено

- каталог оборудования, поиск, фильтрация и сортировка;
- проверка официальных источников QTECH, MikroTik, Eltex, D-Link и Zyxel;
- получение установленной версии по SNMPv1/v2c/v3;
- каталоги и разграничение доступа наблюдателей;
- администрирование пользователей и обязательная смена пароля;
- SMTP-уведомления и ограниченные повторные напоминания;
- автоматическая проверка по расписанию;
- Docker Compose, healthcheck, резервное копирование и восстановление;
- инструкции установки, обновления и эксплуатации.

### Безопасность

- Argon2 для паролей и Fernet для прикладных секретов;
- CSRF-защита, ограничение частоты входа и завершение неактивных сессий;
- проверка URL источников и SMTP-адресов;
- контейнер без root, Linux capabilities и повышения привилегий;
- безопасные HTTP-заголовки и ограничение размера запросов.
